# Canvas prints, Hyderabad

Research for Govinda, read 12 November 2026.

## Purpose

A working page for a side business: design original art, pay a vendor to print it on canvas, do a light finish, and deliver framed or canvas prints to offices, hotels, restaurants, clinics, cafés, showrooms, and co-working spaces in Hyderabad.

The page lists real businesses and public prices. It is not a quote, and it is not part of the portfolio website.

## Who it is for

Govinda, planning the business from Hyderabad. Anyone else should treat the numbers as notes from that date, and check the linked pages before paying.

## How to open it

This folder is already on your computer once you have pulled the repo. No server.

1. In the repo, go to `local/canvas-prints/`.
2. Double-click `index.html`, or drag it onto Chrome, Safari, or Firefox.

The layout styles are inside the file, so the page still shows if the extra Tabler stylesheet does not load. Tabler is optional and loads from a CDN only when the browser can reach it.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The research page: 33 businesses, 55 cost rows, and the public rate cards. Search and filters run in the page. |
| `sources.md` | The pages the numbers were taken from, and the list of prices that were not public. |
| `README.md` | This note. |

## What the page is not

It is not hosted. Do not copy it into `public/`, and do not add a route for it. A pull of this repo is how the file stays available locally.
