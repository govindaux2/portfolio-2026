Motion lab

The same nine composed components, animated by four different motion languages — and five WebGL surfaces showing where shaders earn their place. Switch systems in the Style studio, or hit Compare 4 to see all four side by side reacting to the same click. Slow motion speed down to 0.2× to actually watch what's happening. Every shader takes its colour from the same accent token as the buttons, so the wheel retints the GPU work too.

Command palette stagger + scrim

The hardest overlay to get right. Scrim, container and list items are three separate timings — if they all move together it feels cheap, and if the stagger is too slow it feels sluggish.

Watch: how far the panel travels before settling, and how much delay sits between list rows.

Segmented control shared element

One indicator physically travels between options instead of two states cross-fading. This is the cheapest way to make an interface feel continuous rather than snapped-together.

Watch: Arcade overshoots and settles, Aurora glides, Editorial simply moves, Minimal is nearly instant.

Stat card data reveal

Numbers count up, the sparkline draws itself along its own path, bars grow in sequence. Animating data entry buys you about 800ms of perceived speed for free.

Watch: the line draw duration is a multiple of the base token, so it stays in proportion in every system.

Toast stack enter / exit

Exit animations are always faster than entrances — the user has already moved on. Notice the stack reflows when one leaves rather than jumping.

Watch: Aurora blurs on entry, Arcade pops with overshoot, Editorial only fades and lifts.

Accordion height without JS

Animated with grid-template-rows: 0fr → 1fr, so height transitions smoothly with no measuring, no max-height hacks and no layout thrash. The text fades in slightly after the box opens.

Watch: the chevron rotation is tied to the same duration token as the height.

Multi-step form directional

Panels move in the direction you're travelling — forward slides in from the right, back from the left. Direction is the whole point; without it the user loses their place.

Watch: the progress bar and the dot indicator run on the same easing as the panel.

Draggable deck physics

Drag the top card. Rotation is derived from horizontal distance, and release either flies it out or springs it home. Direct manipulation must track the finger exactly — with zero transition while dragging.

Watch: the transition class is added only on release. That single detail is what makes drag feel real.

Menu transform origin

The menu scales up from the corner nearest its trigger, so it reads as coming out of the button rather than appearing on top of it.

Watch: items cascade in the reading direction, never all at once.

Skeleton → content perceived speed

Skeletons must match the shape of what's coming, and the swap must be a reveal rather than a replace. Aurora unblurs, Arcade snaps, Editorial fades like ink drying.

Watch: content rows share the same stagger token as the palette list.

Shader surfaces

Five cases where a shader does something CSS genuinely cannot: per-pixel refraction, a surface that remembers where your pointer went, and gradients that flow rather than slide. Each one is a fullscreen quad with a single fragment shader, pulling --accent straight from the tokens. They pause automatically when scrolled out of view.

Liquid glass Apple-like

A rounded slab that refracts what's behind it. Bending is strongest at the edges where the virtual glass is thickest, there's a light chromatic split, a specular streak that tracks the pointer, and a bright rim. Move your pointer across it — the slab lags slightly, which is what sells the weight.

This is the honest version of "glassmorphism": real refraction of the content underneath, not a blur filter.

Reactive fluid memory

The surface stores your last twelve pointer positions and emits a damped ripple from each. Faster movement makes taller waves. Normals from the height field drive the lighting.

Drag across meRipples decay over ~2s

Aurora mesh for Aurora

Domain-warped noise — a gradient that flows instead of sliding. This is the background the Aurora system wants behind a hero, and it costs one draw call.

Flowing mesh gradientTwo octaves of warp

Neon grid for Arcade

Perspective floor grid with a horizon glow and scanlines. Pointer height changes the camera, pointer speed changes how fast the grid scrolls.

The four motion languages

Every difference on this page comes from these six tokens. Nothing else about the components changed.

System Duration Easing Stagger What it signals
Minimal 150ms .2,.7,.3,1 26ms Competence. Motion confirms, never performs.
Aurora 560ms .16,1,.3,1 55ms Intelligence and calm. Long tails, blur on entry, things materialise.
Arcade 110ms .2,1.6,.4,1 34ms Responsiveness. Overshoot, scale-down press, glow on contact.
Editorial 420ms .33,.9,.25,1 70ms Authority. Opacity and small travel only — never scale, never bounce.
