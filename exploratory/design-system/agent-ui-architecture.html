Style stack

Type does the hierarchy. Boxes are a last resort. Style systems only write default tokens, so the per-component editor can always win.

Theme file

Export / import JSON. Dark or light, one accent hue, motion speed, reveal grain.

Style system

Minimal, Aurora, Arcade, Editorial change radius, type, motion curve, and default surfaces. Never hard backgrounds that the editor cannot override.

Global tokens

Color ramps, type scale (nothing below 13px), uneven spacing, hairline / tint / wash.

Component colour layer

ask, op, code, user, prose, plan, fan, note, btn, composer, pin. Each exposes text, accent, line, box, plus radius, pad, shadow, sheen.

Stream primitives

Every operation is the same one-line row: icon, verb, target, status. Learn it once and the product is legible.

Locus of action

While a decision is outstanding, the block keeps the detail and the pin bar takes the buttons. Auto-approve counts down in both places. Reject is always the same distance away.
