# Exploratory HTML

Static design references and ideation — **not** part of the Vite app.

## Open this

**[`index.html`](./index.html)** — mobile tab hub. Tap a category, tap a file to preview, or use **Open full page**.

## Layout

| Folder | What |
|--------|------|
| `design-system/` | Active design-system docs (blueprint, checklist, components, motion, neon grid, agent UI, architecture) |
| `archive/` | Legacy dumps (`Agent-UI.html`, `shader-flow.html`) |
| `../portfolio/ideation/` | Portfolio case-study ideation (e.g. design-decision approaches) |
| `../public/dev/` | Dev tooling HTML (linked from the hub) |

Root filenames like `design-system-checklist.html` are thin redirects to the new paths.
