Merge guidance for final QAD package

Source 03 sits beside the card/background source and the header/nav/AI-chat source. Global CSS, tokens, and MD guidance should point to these three files as the styling truth. When instructing an AI agent, paste the rules below — do not invent new button radii, logo-in-button treatments, or mustard/red primary floods.

KeepBlack-to-graphite primary surface, silver horizontal data-dash on click / running, secondary / ghost / danger / loading / icon-only states.
NormalizeIBM Plex Sans, 4px radius, 400/500 weights only. QAD red/orange as signal accents — never as the default primary fill.
ReplaceLarge-radius buttons, logo inside buttons, excessive red fill, mismatched animation, or one-off hover treatments.
AI ruleUse .qad-btn variants only. Graphite primary for analysis actions. Danger stays destructive red. Ghost / secondary for secondary actions on light or dark AI-chat surfaces.

CSS entry point: .qad-btn, .qad-btn--secondary, .qad-btn--ghost, .qad-btn--danger, .qad-btn--small, .qad-btn--large, .qad-btn--icon, .is-loading, .is-disabled, .is-running / .demo-run.
